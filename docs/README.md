## 📖 阅读建议

### 按课次学习（推荐）

跟着课程进度，逐课学习：
1. 先看 `00-课程前言.md` 了解课程目标
2. 按课次顺序阅读各课文档
3. 配合代码目录实践

### 完整版 vs 精简版

| 版本 | 适合 |
|------|------|
| 完整版 | 系统学习，内容详尽（含完整代码和讲解） |
| 精简版 | 快速复习，核心要点 |
